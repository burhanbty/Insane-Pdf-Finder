Kitabın arka kapağındaki 10 veya 13 haneli numarayı gir.

Hocanın verdiği kitabı nasıl bulursun?
  1. Başlık ve yazarı gir. ISBN varsa “ISBN numaran mı var?” alanından kitabın bilgilerini getir.
  2. Sonuçtaki yazar, yıl ve ISBN'yi ders listenle karşılaştır; farklı baskılar olabilir.
  3. Kitabı kitaplığına kaydet, ders adını koleksiyon olarak ekle. PDF/EPUB bağlantısı varsa indirebilirsin; diğer kayıtlarda kaynağı aç.

Kaynaklar

Kitap, makale ve sunum ararken bu katalogları tararız. Her kaynağın sunduğu erişim seçenekleri farklı olabilir.

Geliştirici ayarları

Bazı kaynakların ek seçenekleri için .env dosyasına API anahtarı veya iletişim e-postası eklenebilir.

Kendi kaynağını ekle

src/sources/ klasörüne varsayılan export'u şu biçimde olan bir dosya koy — kayıt defteri onu otomatik bulur: 

export default {
  id: "benim-sitem",
  ad: "Benim Sitem",
  tur: ["kitap", "makale"],
  aciklama: "Ne yaptığını yaz",
  ara: async (sorgu) => [
    { kaynak: "benim-sitem", kaynakAd: "Benim Sitem", tur: sorgu.tur,
      baslik: "...", yazarlar: [], link: "https://...", pdf: "https://..." }
  ]
}
